Files for nextstrain ML phylogenies. All fastas and results which include alignment files have been removed for public git repository. Snakefiles and configs and resulting JSONs are available here. All sequences derived from GISAID are cited in the GISAID acknowledgement table found in this repo as well as in the manuscript supplement. Metadata for all strains used are available here, as they are appropriately attributed to sources (GISAID) or are fully publicly available from NCBI.
